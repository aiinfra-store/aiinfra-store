# 04 · 训练营阶段二：K8s 大模型集群调度、GPU 虚拟化切分与场景调优实战

> **这是公开的简版大纲**：列出全部模块和每一讲的标题。每一讲的详细要点、讲义和实验代码，报名后在课程仓库里看。

> AI Infra 学院 · **训练营**（共两个阶段）。这条线讲的是**怎么把大模型服务交付出去并且跑稳**，和讲原理的特训课、讲深度方向的专精课是并列的两类课。

**服务多到单机管不过来的那一天，就该上这一阶段。** 但**不是把东西全搬上去就叫上集群**——这门课第 01 讲先讲清楚哪些该上、哪些上了反而更差，然后再解决调度、切分、多机推理、弹性与高可用，接着把多集群、流量治理、多租户安全、成本与配额这些**集群长大之后才会冒出来的问题**讲完，最后交付一整套 Helm 部署包。

## 阶段基本信息
* **先修**：完成阶段一，并且熟悉 K8s 基本操作。
* **和阶段一的分工**：**引擎参数怎么调、场景怎么调优，在[阶段一](03-single-node-delivery.md)第 11～25 讲讲透**；这门课讲的是**同样的场景搬到集群上还要多做什么**——调度位置、多实例路由、跨节点 KV 与网络跳数、弹性伸缩。两门不重复。
* **实验素材**：个别讲会拿语音、图像视频生成这类服务当调度与伸缩的实验对象，镜像和配置随课直接提供，`apply` 就能起，不需要先学别的课。
* **课时**：35 讲，每集约 40 分钟。**内容多的 7 讲拆成上下两集**（第 11、12、23、28、29、30、32 讲，大纲里逐讲标明了上下集各讲什么），全课共 42 集、约 28 小时。
* **一句话介绍**：服务多到单机管不过来，先判断哪些服务该上集群，再把它们迁上 K8s，解决调度、切分、弹性伸缩与高可用问题。
* **学完能投**：GPU 集群运维 / SRE、AI 平台工程师、云原生 + AI 方向的中高级岗位。
* **适用人群**：云原生工程师、中高级运维、DevOps / SRE、平台架构师。
* **学完交付**：GPU / NPU 切分方案、Volcano / Kueue 批处理与推训一体调度配置、Multus-CNI 双网络配置、多机推理与 PD 分离部署、弹性伸缩与 Spot 降本策略、故障预案手册、多集群与跨机房切流预案、流量治理与多租户安全基线、集群成本分账与容量测算表、GitOps 仓库与升级 Runbook、整套服务的 Helm 部署包。

## 这门课不教什么

* **不教 K8s 入门**——Pod、Deployment、Service 这些默认你会。这门课从「K8s 怎么管 GPU」开始讲。
* **不教引擎参数怎么调**——那在[阶段一第 11～25 讲](03-single-node-delivery.md)讲透了。这门课讲**同样的服务搬上集群还要多做什么**。
* **不教模型训练**——集群上的训练任务调度会讲（Volcano / Kueue），但训练本身在 [05 分布式训练](05-distributed-training.md)。
* **不教 Slurm 集群怎么搭**——第 01 讲会讲清楚训练侧为什么常用 Slurm、什么时候该是 Slurm + K8s 混合，但 Slurm 本身的部署运维不在这门课里。
* **不教写平台**——这门课用的是开源组件和 Helm。想自己写一套中台，是[另一门课](https://github.com/aiinfra-store/onhold-llmops-platform)（暂无排期）。
* **不教网络工程**——交换机配置与机房组网是网络工程师的活；这门课只讲容器里怎么把 RDMA 用起来、怎么验它真的通了。

**只教一件事**：服务多到单机管不过来之后，**哪些该搬上 K8s**，以及搬上去之后怎么跑得比单机更稳。

## 实验环境与成本

**课程演示全部在真机上做**：一个多节点的真实 K8s 集群（kubeadm 搭建，每个节点带消费级显卡），消费级硬件做不了的三块里，**MIG 硬切分在云上按小时租机演示；Spot 竞价实例与昇腾国产卡只讲原理与配置走读，不做现场演示**，大纲里逐处标明了。**kind / minikube 不是课程的演示环境，是给手上没有机器的学员跟做用的**——下表标清了每个模块用它能做到什么程度。

| 模块 | 课程演示环境 | 没有机器的学员 |
|---|---|---|
| 模块一（上不上集群、GPU 纳管与切分） | 真机集群（NUMA 拓扑用其中一台双路工作站）；MIG 在云上租机演示 | 纳管流程 kind 能走通；切分需要一张真卡 |
| 模块二（国产算力纳管、第一套服务上集群） | 第 06、07 讲**只讲原理与配置走读**；第 08 讲真机集群 | 第 08 讲一张真卡就能做；昇腾部分配套 YAML 随课提供 |
| 模块三（Volcano / Kueue、容器 RDMA） | 真机集群；RDMA 用两台机器网卡直连 | 调度部分 kind 能完整复现（不需要 GPU）；RDMA 部分看演示与抓包数据 |
| 模块四（多机推理与 PD 分离） | 真机集群（两个 GPU 节点） | 需要两台带卡的机器，按量租几小时 |
| 模块五（三大场景上集群） | 真机集群 | 单卡能做大部分，跨节点部分需要两台 |
| 模块六（模型存储、镜像分发、灰度升级） | 真机集群，用限速复现大规模下的现象 | kind + 普通云主机即可 |
| 模块七（弹性伸缩、监控、高可用） | 真机集群；Spot 只讲原理 | 伸缩策略、监控、演练流程 kind 能做，**但看不到真实的模型加载耗时** |
| 模块八（多集群、流量治理、多租户安全） | 两台真机各装一个单节点集群，Karmada 联邦；集群间用 `tc netem` 模拟跨地域网络 | kind 起两个集群能走通流程，**GPU 分发与切流效果看演示** |
| 模块九（成本与配额治理、GitOps、集群运维） | 真机集群 | kind 能做，分账报表里的 GPU 数据用课程提供的样本 |
| 阶段通关项目 | 真机集群 | 两台带卡的机器，按量租用几小时，用完即停 |

**哪些实验 kind 做不出效果，这里先说清楚**：GPU 切分、多机推理、PD 分离、扩容时延、跨机房切流——这几项都需要真卡。课程每一讲开头都标了「本讲最低环境」。
