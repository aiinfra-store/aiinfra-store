## 课程基本信息
* **先修**：完成训练营阶段二（K8s 集群），并且熟悉 Python 与 K8s。
* **一句话介绍**：手写一套企业 AI 中台，统一管理全部模型服务，接入双层网关实现多租户与计费。
* **适用人群**：架构师、技术总监、资深开发。
* **学完交付**：LLMOps 中台源码（Vue3 + FastAPI，含 MLOps 模型交付流水线与压测评测中心）、New-API + Higress 网关对接代码（含 MCP 纳管与数据飞轮）、故障诊断 Agent 代码、全套 Helm 部署包。
* **源码授权**：仅限购买者本人学习及所在企业内部使用，以购买协议为准。
