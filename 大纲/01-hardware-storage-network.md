# 《从物理底座到万卡集群：大模型 AI Infra 硬件、存储与网络第一性原理特训课》

本课程为一套面向云计算架构师、Kubernetes 运维、SRE、高性能计算与平台后端工程师的硬核进阶特训课，系统涵盖：**算力物理学第一性原理 ➔ GPU 芯片微架构 ➔ 显存与磁盘 I/O 底层 ➔ 机内高密总线与服务器工程 ➔ 800G RDMA 无损网络 ➔ 分布式集合通信（NCCL） ➔ 承上启下工程图谱 ➔ 结业综合模拟卷与面试题视频深度解析**。

---

## 这门课不教什么

* **不教怎么部署模型**——不讲 vLLM 怎么起、参数怎么调、服务怎么上线。那在 [03 训练营阶段一](03-single-node-delivery.md)。
* **不教 K8s 和集群运维**——这门课讲的是集群底下那层物理原理，集群本身在 [04 训练营阶段二](04-k8s-cluster.md)。
* **不教模型结构与算法**——Transformer、注意力、显存怎么算在 [02 大模型系统基础](02-llm-system.md)。两门是并排的地基：这门讲**机器怎么跑**，那门讲**模型怎么跑**。
* **不教写代码**——这门课的实操是测量、算账、抓包、画图，不要求 C++ 或 CUDA。想写算子去 [06 算子开发与优化](06-gpu-kernel.md)。
* **不教交换机配置与机房规划**——那是网络工程师的活；这门课讲的是**为什么要这么组网**，以及出问题时怎么判断是哪一层。

**只教一件事**：把「算、搬、传」三笔账算清楚，看一台机器就知道它能跑什么、瓶颈在哪、再采购该改哪几项规格。

## 二、 课程主线：从一颗芯片物理微观世界，到万卡无损网络集群

本课程是整个课程体系的**地基课**，也是后面所有课的**核心前置打底基石**。它回答「机器怎么跑」，另一门地基课《大模型系统基础》回答「模型怎么跑」。两门打完底再往上走：要么走**训练营两个阶段**（把服务交付出去并且跑稳），要么挑一门**专精课**（把某一层做到别人做不了的深度）。

本课不讲虚浮概念，完全从**物理世界第一性原理**出发，顺着数据在计算系统中的微观物理流动路径逐层展开：

| 物理层次 | 涵盖核心物理实体 | 解决的核心物理本质问题 | 对后续课程的直接决定作用 |
| :--- | :--- | :--- | :--- |
| **计算微观层** | SM 核心、Warp 调度器、Tensor Core、MMA 阵列、MFU 精算 | 为什么 GPU 算矩阵快？为什么分支分化算力暴跌？千卡 MFU 算力损耗在哪里？ | 直接决定后续 vLLM CUDA Graph 固化、批处理 Token 预算与算子优化 |
| **数据载体层** | HBM3e、NVMe SSD、Page Cache、`mmap` 零拷贝、GPUDirect Storage | 显存带宽墙如何突破？Linux 内核 I/O 怎么搬运百 GB 权重？GDS 如何绕过 CPU？ | 直接决定后续 Safetensors 加载、JuiceFS CSI 缓存加速与冷启动秒级拉起 |
| **机内互联层** | PCIe 5.0 Switch、UPI 总线、NVLink 4/5、NVSwitch、Row Remapping | 跨 CPU 访问为什么延迟显著上升？为什么 4090 无法跨卡 TP？显存出现坏道如何诊断？ | 直接决定后续 K8s NUMA 亲和性调度、GPU Operator 拓扑感知与坏卡自愈 |
| **跨机通信层** | 800G OSFP、ConnectX-7、Spine-Leaf CLOS、Rail-Optimized、RoCEv2 | 为什么传统 TCP 瘫痪？万卡导轨网络如何消除拥塞？PFC 暂停帧死锁如何形成？ | 直接决定后续 Multus-CNI 动静网络隔离、GPUDirect RDMA 生产部署与网络排障 |
| **并行算法层** | AllReduce、Ring 算法、Tree 拓扑、NVLS、3D 并行 | 为什么 Ring 算法的带宽开销几乎与卡数无关？大模型各并行维度的网络带宽要求是什么？ | 直接决定后续 Volcano Gang 调度、LeaderWorkerSet 多机推理与 NCCL 排错 |
