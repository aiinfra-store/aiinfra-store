# 02 · 大模型系统基础（35 讲）

> **这是公开的简版大纲**：列出全部模块和每一讲的标题。每一讲的详细要点、讲义和实验代码，报名后在课程仓库里看。

> 状态：大纲 v2 2026-11-10（逐讲）
> 定位：**所有专精课的共同前提**。特训课讲「机器怎么跑」，这门讲「模型怎么跑」。
> 内容两块：**Transformer 结构**（模块一，10 讲：注意力 MHA / GQA / MLA、FFN 与 MoE、归一化与位置编码、分词器、长上下文扩展、多模态结构）+ **PyTorch 工程**（模块三、四：亲手写出推理与训练循环，读改真实开源实现）。
> 不讲：模型算法设计、调参调效果、论文复现。只讲 Infra 工程师需要的那部分模型知识。

## 学完能做什么

1. **把 Transformer 的每个零件都认得出、算得清**：注意力（MHA / GQA / MLA）、FFN 与 MoE、归一化、位置编码、分词器各自在干什么，看到一个模型的配置文件（hidden size、层数、专家数、注意力类型），能手算参数量、显存占用和每 token 的运算量。
2. 说清一个请求从进来到吐出第一个字、再到吐完，中间都发生了什么。
3. 说清训练一步里，前向、反向、优化器各占多少显存和多少算力。
4. 能用 PyTorch 跑通一个小模型的训练和推理，读懂分布式训练代码，并用 Profiler 看出时间花在哪。
5. **亲手写出**最小推理循环、最小连续批处理、最小训练循环——这样再去读 vLLM 和 Megatron 的时候，看到的是工程化，不是魔法。
6. 拿到一份真实的开源模型实现，能认出里面每个零件，并改动其中一处（比如把 MHA 换成 GQA）让它还能跑。

## 这门课不教什么

* **不教怎么训出一个好模型**——不讲数据配比、超参搜索、算法改进。这是**系统课**，讲的是模型在机器上怎么跑。
* **不教部署和运维**——不讲 vLLM 怎么起、参数怎么调、服务怎么暴露。那在 [03 训练营阶段一](03-single-node-delivery.md)。
* **不教分布式训练工程**——并行策略、ZeRO / FSDP、断点续训在 [05 分布式训练](05-distributed-training.md)，这门课只打到「单机能跑通一个训练循环」为止。
* **不教写 CUDA**——算子怎么写在 [06 算子开发与优化](06-gpu-kernel.md)。

**只教一件事**：看懂一个模型，并且能把「它要多少显存、多少算力、跑多快」算出来——**这是后面所有课共用的那套算账方法**。

## 交付物清单：35 讲攒出一个什么

这门课不是「35 讲听完再做一个大作业」。**每个模块结束你手上都多一个能单独拿出去的东西**，最后的结业项目是把它们装成一个仓库，而不是从零开始写：

| 模块 | 这个模块结束时，仓库里多了什么 |
|---|---|
| 模块一：模型长什么样 | `model-anatomy/` config 解剖脚本 + 结构验证与曲线 |
| 模块二：三笔账：参数量、算力、显存 | `calc.py` 三笔账脚本（后面每门课都要用） |
| 模块三：模型怎么跑起来 | `mini-system/` 推理 / 连续批处理 / 训练三个最小循环 |
| 模块四：上手：从张量到分布式 | 装成一个能跑的最小大模型系统 + 误差曲线 |

一条命令能跑完、一份报告能讲清——**结业时你手上的，是一个能直接发出去的 GitHub 链接，不是一张结课证明。**
