## 课程基本信息
* **先修**：完成训练营阶段一，或者已经熟悉 Docker 与 vLLM。
* **一句话介绍**：私有化部署语音识别、语音合成、视觉理解、实时语音、图像与视频生成模型，并全部接入 New-API，用一个 API Key 统一调用、计量与管理。
* **适用人群**：运维工程师、SRE、后端开发、AI 平台工程师。
* **学完交付**：语音识别 / 语音合成 / 实时语音部署模板、视觉与 Omni 模型部署方案、具身动作模型（VLA）服务化适配方案、图像视频生成服务化方案、ComfyUI 部署与自定义节点源码、OpenAI 兼容适配层源码、New-API 多模态接入与计费配置。

## 实验环境与成本

**这是全部课程里对显卡最友好的一门**——多模态模型普遍比大语言模型小得多。

| 模块 | 环境 | 说明 |
|---|---|---|
| 模块一（多模态全景、架构与合规） | 零硬件 | 架构选型与合规梳理 |
| 模块二（ASR / TTS 生产部署） | 单卡（显存要求低） | 语音模型普遍很小，消费级卡完全够 |
| 模块三（视觉理解、全模态与实时语音） | 单卡 | 全模态与实时语音交互那几讲建议显存大一些 |
| 模块四（图像视频生成与 ComfyUI） | 单卡，显存越大越舒服 | 视频生成吃显存，课程会给降分辨率 / 降帧数的复现方案 |
| 模块五（统一接入 New-API） | 普通云主机 | 网关、鉴权、限流、计费这部分不吃显卡 |
| 通关项目 | 单卡，集中用几小时 | 按量租用即可 |

**全程单卡可完成**，不需要多卡或多机。
