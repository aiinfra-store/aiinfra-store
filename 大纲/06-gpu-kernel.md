> **这是公开的简版大纲**：列出全部模块和每一讲的标题。每一讲的详细要点、讲义和实验代码，报名后在课程仓库里看。

> 状态：大纲 v2 2026-11-10（逐讲）
> 对应岗位：算子 / Kernel 工程师
> 先修：《大模型系统基础》（02）。《特训课》（01）的 GPU 微架构与 Roofline 模块**推荐但不强制**，必需的那部分第 07 讲会速览
>
> **编程门槛（这门课最重要的前提）**：这门课不教 C / C++，默认你能读写 C 风格代码——指针与内存布局、数组与结构体、基本的模板用法。如果这块还不熟，建议先用两三周补一下 C 基础，上课会轻松很多
> 后续：《模型适配》、《AI 编译器》都建议先学完这门

## 这门课不教什么

不教 C / C++ 语法（第 02 讲只补最少的那几样，不替代系统学一遍 C++）、不教模型结构、不教编译器实现（那是《AI 编译器》）。**只教怎么把一个算子写快**：从能跑对，到逼近官方库。

## 学完能做什么

1. 用 CUDA 和 Triton 写出接近官方库性能的算子，并用得上 TMA、warp specialization 这些现代架构机制。
2. 拿到一个慢算子，能用 Profiler 判断它卡在访存、计算、同步还是调度，并逐步优化。
3. 把自己写的算子接进 PyTorch，再接进一个真实推理引擎（vLLM / SGLang）跑端到端，并用 benchmark 与回归检查守住已有收益。
4. 面试时能讲清 FlashAttention 为什么快（v2 和 v3 分别快在哪）、GEMM 怎么一步步优化。

## 课程主线

**先会量，再会调；先把访存密集型算子榨干带宽，再把计算密集型算子榨干 Tensor Core；最后让搬运和计算彻底解耦。**

每一个算子都走同一套流程：算出理论上限 → 写出朴素版 → 用 Profiler 找瓶颈 → 改一处、测一次、解释为什么 → 直到贴近上限。**课程要求每一步优化都有数据和解释，不接受「我改了一下就快了」。**

## 模块二：性能分析方法（第 07～10 讲）

> **这个模块结束**：拿到一个慢模型，你先用 Nsight Systems 看整条时间线定位到该优化哪个 kernel（**很多时候问题根本不在 kernel 里，而是在启动开销**），再用 Roofline 判断该优化访存还是算力、用 Nsight Compute 读出瓶颈，而不是凭感觉乱改。**这个模块是后面所有优化的前提。**
>
> **本模块交付**：`profiling/` —— 十个常见算子的算术强度表与优化优先级排序、一份只凭 Nsight Compute 报告写出的瓶颈判定、一次真实模型时间线上的三处 GPU 空闲归因（含用 CUDA Graph 消掉启动开销的前后数据）

## 结业项目怎么写进简历

**这是最容易「以作品换面试」的一门课**，因为算子有硬指标：快就是快，跑一下就知道。简历上最值钱的就是那个百分比。

**项目名这样写**：`高性能 GPU 算子库：GEMM 与注意力 kernel，接入 vLLM / SGLang（测试卡型：〔你的卡〕）`

| ❌ 常见写法 | ✅ 该怎么写 |
|---|---|
| 熟悉 CUDA 编程 | 手写 tiled GEMM，**在〔卡型〕上做到 cuBLAS 的 X%**，仓库里有逐步优化记录：每一步改了什么、提升了多少 |
| 了解 FlashAttention | 实现分块注意力 kernel，**性能达到官方实现的 X%**，并接进 vLLM / SGLang 跑通真实请求 |
| 会用 Triton | 用 Triton 重写同一个算子，**代码量减到原来的 1/N，性能是手写 CUDA 的 X%**，并说清差距来自哪 |
| 做过性能分析 | 用 Nsight Compute 定位到〔某个瓶颈〕（非合并访存 / bank conflict / 寄存器溢出），**消除后单 kernel 耗时下降 X%** |

> **X、Y、〔〕里的内容填你自己实测出来的数和实际用的环境**，上面是写法不是模板。三条规矩和训练营阶段一的同名一节相同：数字优先、技术栈靠后；一条经历写清动作、结果和**代价**；规模如实写。

**规模如实写**：写明测试的卡型和对比基线的版本号。课程达标线是 GEMM 做到 cuBLAS 的八成、注意力做到官方实现的七成——**没到就写实际数，别凑**。仓库必须一条命令能复现 benchmark。

**技术面被追问时，你应该当场答得出来的**（课程里都练过）：

* 「现场手写一个 reduce 或 GEMM」→ 模块一、四反复练过
* 「这个 kernel 为什么慢」→ Roofline 加 Nsight Compute 的分析路径（模块二）
* 「你的实现和 cuBLAS 差在哪」→ 优化记录里的最后那几个百分点

## 实验环境与成本

| 阶段 | 最低要求 | 说明 |
|---|---|---|
| 模块一～四 | 一张 NVIDIA 消费级显卡 | 全程单卡，不需要多卡多机 |
| 模块五（Tensor Core、TMA、FP4） | **Hopper 或更新架构的卡；第 23 讲的 FP4 需要 Blackwell** | 第 20 讲的 TMA、warp specialization、线程块簇需要较新架构，消费级卡做不了；按小时租云上实例，用量集中 |
